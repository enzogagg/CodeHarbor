# Code Of Conduct

CodeHarbor aims to be a practical and respectful developer tool project.

## Expected Behavior

- Be direct and constructive.
- Assume good intent.
- Keep discussions focused on improving the project.
- Respect maintainers' time and project scope.

## Unacceptable Behavior

- Harassment or personal attacks
- Publishing private information
- Deliberately disruptive behavior
- Repeatedly ignoring project boundaries or contribution guidance

Maintainers may remove content or block participation that harms the project or its contributors.
