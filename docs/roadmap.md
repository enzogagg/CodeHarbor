# Roadmap

## 0.1.0 - Initial Project Structure

- Apache 2.0 license
- Repository documentation
- Docker AMD64 code-server prototype
- Lightweight Tauri product skeleton
- Initial templates and docs

## 0.2.0 - Docker Detection And Workspace Listing

- Detect Docker Desktop availability
- Validate Docker Compose support
- List known environments from local metadata

## 0.3.0 - Environment Creation

- Create an environment from a template
- Choose architecture, ports and local folder mount
- Generate Compose and Dockerfile assets

## 0.4.0 - Environment Lifecycle

- Start environments
- Stop environments
- Delete environments
- Display status and mapped ports

## 0.5.0 - Logs And Terminal

- Display Docker logs
- Add shell access
- Add terminal UI integration

## 0.6.0 - code-server Integration

- Open IDE from the desktop app
- Manage code-server configuration
- Improve persistent workspace settings

## 1.0.0 - Stable MVP

- Reliable local workflow
- Reproducible generated environments
- Documented installation and upgrade path
