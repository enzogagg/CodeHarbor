# Tauri Desktop MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable Tauri desktop app that controls the existing CodeHarbor Docker prototype.

**Architecture:** The frontend is a Vite React TypeScript app in `src/`. The backend is a Tauri Rust app in `src-tauri/` exposing commands that call Docker Compose in `prototype/docker-workspace/` and open code-server in the browser.

**Tech Stack:** npm, Vite, React, TypeScript, Tauri, Rust, Docker, Docker Compose.

## Global Constraints

- Use npm as the package manager.
- Keep the prototype Docker files in `prototype/docker-workspace/`.
- The app controls only the existing `Ubuntu AMD64 Workspace` in this milestone.
- Do not add SQLite, user-created environments, template editing, integrated terminal, account management or packaged release automation.
- Tauri commands are named `check_docker`, `start_prototype`, `stop_prototype`, and `open_ide`.
- The frontend invokes commands with `@tauri-apps/api/core`.
- Buttons are disabled while a command is running.
- Commit implementation changes after build checks pass.

---

## File Structure

- `package.json`: npm scripts and frontend/Tauri dependencies.
- `package-lock.json`: npm dependency lockfile generated by `npm install`.
- `index.html`: Vite HTML entrypoint.
- `tsconfig.json`: TypeScript project configuration.
- `tsconfig.node.json`: TypeScript config for Vite tooling.
- `vite.config.ts`: Vite React configuration.
- `src/main.tsx`: React bootstrap.
- `src/App.tsx`: CodeHarbor MVP screen and Tauri command calls.
- `src/App.css`: desktop UI styling.
- `src/vite-env.d.ts`: Vite type declarations.
- `src-tauri/Cargo.toml`: Rust package and Tauri dependencies.
- `src-tauri/build.rs`: Tauri build script.
- `src-tauri/tauri.conf.json`: Tauri app configuration.
- `src-tauri/capabilities/default.json`: permissions for the main window.
- `src-tauri/src/main.rs`: Rust entrypoint and Docker/browser commands.
- `docs/development.md`: updated desktop app development commands.
- `README.md`: updated desktop app test instructions.
